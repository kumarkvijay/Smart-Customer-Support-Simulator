# TechGear AirLite 14 User Manual

## Display troubleshooting
For screen flicker, first confirm whether the issue appears only on battery power or also when the charger is connected. Set the display refresh rate to 60 Hz, restart the device, and install the latest graphics driver from TechGear Support. Disable adaptive brightness before testing again.

If the internal display still flickers, connect an external monitor. If the external monitor is stable, the laptop panel or display cable may require service. If both displays flicker, run a driver cleanup and reinstall the graphics package.

## Password reset
Press F12 during startup and choose Recovery Mode. Select Reset Password and continue the guided setup flow. Devices protected by BitLocker require the recovery key before the reset can be completed.

## Thermal care
Do not block air vents. Clean dust from the cooling path every three months in dusty environments. Sustained overheating can trigger performance reduction and fan noise.
