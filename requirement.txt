How all 4 technologies work together in one project

RAG (Retrieval-Augmented Generation)
You create a private knowledge base: PDFs/manuals + FAQ JSON + 20–30 example past tickets.
Everything is chunked and stored in Chroma (or FAISS).
Every user query first retrieves the most relevant chunks → no hallucinations.

AI Agent (LangGraph ReAct style)
The brain of the system.
It doesn’t answer directly. It thinks step-by-step:
“Is this a simple FAQ?”
“Do I need to retrieve more docs?”
“Do I need to use a tool (order lookup, ticket creation)?”
“Is the answer confident enough?”

Uses LangGraph to create a clear state machine (you can literally draw the flow).

LLM (Large Language Model) – e.g. Llama 3.1 8B via Ollama
Used only when reasoning is complex (multi-step troubleshooting, empathetic long replies, comparing products).
High quality but slower and uses more GPU/CPU.

SLM (Small Language Model) – e.g. Phi-3-mini 3.8B or Gemma-2-2B via Ollama
Runs on CPU or even a laptop with 8 GB RAM.
Handles: intent classification, quick FAQ answers, confidence scoring, first-pass summarization.
Privacy superpower: never touches the cloud, perfect for sensitive customer data.


Smart Routing (the magic part):
A tiny router node (can even be rule-based or a tiny SLM call) decides:
→ Simple query? → SLM + RAG (super fast & private)
→ Complex or low-confidence? → Hand over to LLM + full Agent

Pythonfrom langchain_community.document_loaders import JSONLoader, PyPDFLoader, DirectoryLoader
from langchain_text_splitters import RecursiveCharacterTextSplitter
from langchain_chroma import Chroma
from langchain_ollama import OllamaEmbeddings, ChatOllama
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser
from langchain_core.runnables import RunnablePassthrough
import json
import os

# ------------------- Load Documents -------------------
def load_knowledge_base(kb_path: str = "knowledge_base"):
    documents = []
    
    # Load JSON FAQs and tickets
    json_loader = DirectoryLoader(kb_path, glob="**/*.json", loader_cls=JSONLoader,
                                  loader_kwargs={"jq_schema": ".[]", "text_content": False})
    documents.extend(json_loader.load())
    
    # Load PDFs (manuals)
    pdf_loader = DirectoryLoader(kb_path, glob="**/*.pdf", loader_cls=PyPDFLoader)
    documents.extend(pdf_loader.load())
    
    return documents

# ------------------- Build Vector Store -------------------
def build_vector_store(docs, persist_directory="chroma_db"):
    text_splitter = RecursiveCharacterTextSplitter(chunk_size=800, chunk_overlap=100)
    splits = text_splitter.split_documents(docs)
    
    embeddings = OllamaEmbeddings(model="nomic-embed-text")  # or "mxbai-embed-large"
    
    vectorstore = Chroma.from_documents(
        documents=splits,
        embedding=embeddings,
        persist_directory=persist_directory
    )
    return vectorstore

# ------------------- Retriever -------------------
def get_retriever(vectorstore, k=4):
    return vectorstore.as_retriever(search_kwargs={"k": k})

# ------------------- RAG Chains (SLM and LLM) -------------------
def create_rag_chain(llm_model_name: str, retriever):
    llm = ChatOllama(model=llm_model_name, temperature=0.3)
    
    prompt = ChatPromptTemplate.from_template(
        """You are a helpful, polite customer support agent for TechGear Store.
        Use ONLY the following context to answer the question.
        If you don't know, say "I don't have enough information" and suggest escalating.
        
        Context: {context}
        
        Question: {question}
        
        Answer:"""
    )
    
    def format_docs(docs):
        return "\n\n".join(doc.page_content for doc in docs)
    
    chain = (
        {"context": retriever | format_docs, "question": RunnablePassthrough()}
        | prompt
        | llm
        | StrOutputParser()
    )
    return chain

# ------------------- Usage Example -------------------
if __name__ == "__main__":
    if not os.path.exists("chroma_db") or len(os.listdir("chroma_db")) == 0:
        docs = load_knowledge_base()
        vectorstore = build_vector_store(docs)
    else:
        embeddings = OllamaEmbeddings(model="nomic-embed-text")
        vectorstore = Chroma(persist_directory="chroma_db", embedding_function=embeddings)
    
    retriever = get_retriever(vectorstore)
    
    # Test both models
    slm_chain = create_rag_chain("phi3:3.8b", retriever)      # or your SLM
    llm_chain = create_rag_chain("llama3.1:8b", retriever)
    
    query = "What is the return policy for laptops?"
    print("SLM Answer:", slm_chain.invoke(query))
    print("\nLLM Answer:", llm_chain.invoke(query))

Embedding model not found: Run ollama pull nomic-embed-text
Chroma persistence: Delete the chroma_db folder if you change documents.
Memory usage: If your machine struggles, reduce chunk_size or use fewer documents initially.
